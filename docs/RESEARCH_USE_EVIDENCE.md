# Research use and JOSS evidence

- Original author's Zenodo research preprint: https://doi.org/10.5281/zenodo.24299509
- Public MIT-licensed source repository and GitHub Actions unit tests.
- Recomputed original Chess1 confidence/near-surface numerical results.
- Recomputed Motorcycle depth metrics and 301,197-point PLY reconstruction.
- Reusable APIs and documented opt-in regression tests.

## Evidence NOT currently established

- Independent third-party scientific users or citations of this **software package**.
- A sustained development history prior to this repository's creation.
- Validation on additional unseen datasets or reproducibility across multiple systems.
- A distinct implemented/evaluated CONFIDENCE_AWARE policy versus STRICT_LR.
- Real-world navigation safety, accessibility user study, or haptic outcomes.

Do not fabricate independent users, citations, acceptance, or safety evidence. Before JOSS submission, seek real scientific adoption, feedback/issues from external users, additional examples, and check the journal's current scope and review requirements.
